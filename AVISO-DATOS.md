# Sobre los datos

La licencia MIT cubre el **código**. Los datos tienen otras reglas:

- **Los reportes de las personas** son datos personales tratados bajo la
  **Ley 1581 de 2012** de Colombia, con la autorización que cada quien dio al
  publicar. **No se ceden con la licencia del código** y no se pueden
  redistribuir como un conjunto de datos.
- **La ubicación pública va desplazada ~100 m** a propósito. Quien opere una
  copia de este software no debe publicar la coordenada exacta: está en la base
  solo para moderación y para organizaciones que van al sitio.
- **Mapas base**: OpenStreetMap, bajo ODbL.
- **Geografía municipal**: fuentes oficiales colombianas (DANE, Registraduría).
- **Centros de acopio**: se publican **sin verificar** salvo los que digan
  "revisado". Quien reuse este código debe conservar esa distinción a la vista:
  mandar gente con mercados a una dirección equivocada cuesta gasolina y tiempo
  que en una emergencia no sobran.
